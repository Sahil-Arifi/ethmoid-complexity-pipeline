## Separator evidence

All eight failures contain at least one hard separator between raw regions carrying the same declared core. There are ten such false constraints and six required preserved constraints in those scenes. Replaying the existing contraction exactly reproduces all eight saved merged arrays. Removing only the ten oracle-identified false constraints, while retaining every other hard constraint and the existing scores, satisfies all eight graph-level spatial oracles.

This intervention uses reference information that automatic inference does not have. It is not eight successful automatic predictions, and it does not rerun acceptance on the changed groups. It demonstrates a sufficient graph-stage correction and identifies the component that must supply better observed evidence.

Neither support fraction nor a minimum interface size separates the edges: every false and required edge has support fraction 1; false interfaces have 1, 8 or 11 faces, while required ones have 1, 2 or 7. Exterior-bone rejection alone is also insufficient: six false constraints borrow actual internal sheet or fold bone. Earlier ownership and bone-ray alternatives remain rejected.

`partition_audit.py` adds two diagnostic helpers, without a production caller. The partial-core ledger reports missed and extra foreground separately. The exhaustive reference enumerates partitions of at most eight nodes under an explicit sum-of-cut-costs objective and hard relations. It counts tied optima and leaves missing edges unconstrained. This objective is a diagnostic comparator, not the current greedy policy's optimization contract or an anatomical model. A three-node regression shows that even exact optimization cannot overcome a false hard separator.

## Coverage is a separate policy dependency

Eleven procedural scenes and seven contrasts independently vary membership, exclusions and search. With HU, membership and exclusion fixed, subtracting already-excluded voxels from search leaves free space, distance, raw regions and merged regions byte-identical. It nevertheless creates an unsupported search boundary: a resolved 1,600-voxel region changes from accepted to rejected, and air assignment falls from 1,816 to 216 voxels. Excluded tissue is never assigned.

This explains how coverage can fall without a partition change. It does not establish that accepting an open excluded interface is anatomically justified. Membership-only changes also cause their documented rejection; all observed air is accounted for by acceptance, pre-exclusion, absence of a label or the first rejecting gate. No coverage threshold is relaxed.

## Quarantined same-side correction

A preregistered observed-normal experiment found that two-sided lumen evidence retains all ten false constraints. Adding opposite raw-region centroid sides rejects only the two false constraints near the perforated sheet; the eight false neck/fold constraints remain. This feature was rejected as a complete discriminator, without a parameter search.

The narrower candidate `normal-same-side-veto-quarantine-0.1` removes an originally hard separator only when every selected nearest-plate witness has a nondegenerate observed normal and both raw-region centroids lie strictly on the same side. Missing, degenerate or zero-sign evidence retains the original constraint. Gaussian scale comes from the existing physical plate-width setting. Reference cores, target counts and generator identities never enter this rule.

Independent source review confirmed that the only merge change removes those vetoed edges from the original hard-constraint set. The full compartment stage, including acceptance, then ran once on the 132 sealed inputs with original spatial oracles:

## Independent validation set

Before candidate inference on it, a separate author froze 48 unique geometries across eight structural families, with air, opaque and mixed contents giving 144 HU arrays. There are 37 count-assessable geometries and 11 explicit unknowns; unknowns cannot count as passes. Independent review reconstructed all 48 geometry equations, checked all 101 sealed files and verified 111 negative oracle contrasts. No counting method has run on this set.

The narrow repair is not promoted. The [repair checklist](COUNTING_REPAIR_TASKS.md) still requires an observed rule for the neck/fold errors, all original and representation controls, independent geometry evaluation, and repeated eight-study development comparison. The remaining defect is broader separator identity: nearby thin bone and opposite centroid sides do not establish that the bone partitions a cavity. It remains an engineering obligation, separate from clinician reference questions.

External evidence groups also include `stage-ledger` (132 inputs and complete stage ledger), `fixed-basin-edges` (constraint intervention), `coverage` (fixed-partition gate contrasts), and `independent-geometry` plus `independent-geometry-peer-review-01` (sealed fixtures and independent verification). Earlier failures and all original outputs are retained locally.
